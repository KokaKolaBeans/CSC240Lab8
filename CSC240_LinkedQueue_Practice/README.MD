Files Included

1. **QueType.h** (in CSC240_LinkedQueue_Practice.zip) — a linked queue implementation. This is your starting point: build from it, using only the rear pointer, to make the queue circular.

2. **CSC240_LinkedQueue_Driver.cpp** — a sample driver for that queue

3. **QueType.h** (in CSC240DynamicArrayQueue.zip) — the dynamic array implementation, with evacuateDriver.cpp, a queue simulation. Reference only, for the array-versus-linked comparison — do not build this lab on it.

4. **pointersShallowDeepCopy.cpp** — supplemental. Worked example of shallow versus deep copy; read it before writing your copy constructor.
